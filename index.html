FIGRID — Cybernetic Speed Typing & Reflex Matrix Game

FIGRID is a competitive browser-based speed-typing and neural reflex matrix game playable on both desktop keyboards and mobile touch devices.

Game Modes

  • LINEAR (21x13 Speed Matrix): Clear 273 cells sequentially at maximum velocity with reinforced 2x shields and secret sequences.
  • OMNI-8 (Quantum Matrix): Navigate an 8-directional branching grid starting from the center cell.
  • BINARY (8x8 3-Bit Decoder): Decode digits in real time using 3-bit binary input and XOR-7 overclock chains.
